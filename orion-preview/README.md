# Orion Mall concept preview

This is a standalone preview, not a WordPress theme or a change to the live site. The hero embeds the user-provided YouTube video (`EaEdZmbsStI`). The still image remains as a fallback if the embed is unavailable. Reduced-motion users see the fallback by default.

The footer is an Orion-specific, simplified React adaptation of the supplied Doodle Crew concept, in `components/ui/doodle-crew-footer.tsx`. Its internal navigation points to preview pages. It does not reproduce all features or props of the supplied component.

To rebuild the standalone preview footer after editing the component:

```sh
npm ci --prefix orion-preview
NODE_PATH="$PWD/orion-preview/node_modules" ./orion-preview/node_modules/.bin/esbuild orion-preview/footer-entry.tsx --bundle --minify --format=iife --outfile=orion-preview/footer.js --loader:.css=empty
python3 -m http.server 4173 --bind 0.0.0.0 --directory orion-preview
```

The repository already has shadcn configured with components in `components/ui`, global styles at `app/globals.css`, TypeScript, Tailwind, and React. The preview uses its own `style.css` and `footer.css` because it is a standalone static prototype, not the existing app.

The preview includes the main sections and category pages generated by `python3 orion-preview/create-pages.py`. These are design previews with selected highlights, not a complete WordPress content migration. Internal section links stay in the preview; directions, booking, phone, email and social links lead to external services. The same React footer mounts on every generated page.

## WordPress export content

The preview includes published pages, posts and events from the user-provided WordPress export. To refresh it, run `python3 orion-preview/create-pages.py` followed by `python3 orion-preview/import-wordpress.py /path/to/export.xml`. The importer uses the exported `content:encoded` fields and public media URLs, removes executable or embedded content, and rewrites known internal links. WordPress shortcodes, Elementor templates, plugin-generated content, forms, shop and booking functionality cannot be reproduced from this content alone and require a WordPress staging environment. The export is not included in this repository. The public site and media are unchanged.

To match explicitly associated Elementor category backgrounds and event featured media, also run `python3 orion-preview/place-media.py /path/to/export.xml` after the import. WordPress media files remain hosted by the existing site; this script does not upload or clone them.

The optional `add-elementor-media.py` script adds separate page-associated media galleries. These galleries were removed from the preview at the user’s request; do not run it unless they should be restored.

## Homepage arc carousel

The homepage brand feature uses a moving floor-by-floor directory instead of the earlier wheel. It includes 56 listings extracted from the available WordPress category pages, with hover and keyboard-focus pause, manual scrolling and a static reduced-motion mode. Select a brand for its category and floor. Some export listings have missing logos, inconsistent text or conflicting floors; these are labelled or use a name in place of a logo. Confirm the directory with mall management before publication. `build-brand-data.py` regenerates `data/brands.json` from the imported category pages, and will stop if their listing counts change so the curated names can be reviewed. The separate homepage photo feature uses `components/ui/photo-card-grid.tsx`.

The repository already has the shadcn UI directory, React, TypeScript and Tailwind configuration; the standalone preview uses `carousel.css` instead of Tailwind utilities. To rebuild the carousel after changes:

```sh
npm ci --prefix orion-preview
NODE_PATH="$PWD/orion-preview/node_modules" ./orion-preview/node_modules/.bin/esbuild orion-preview/carousel-entry.tsx --bundle --minify --format=iife --outfile=orion-preview/carousel.js
```

The page generators can overwrite manual preview changes, including this carousel; reapply the homepage integration after regenerating.

Rebuild the brand wheel with:

```sh
NODE_PATH="$PWD/orion-preview/node_modules" ./orion-preview/node_modules/.bin/esbuild orion-preview/brands-entry.tsx --bundle --minify --format=iife --outfile=orion-preview/brands.js
```

## Clothing store photo folders

The Clothing, Footwear, Cosmetic / Unisex Salon, Accessories, Chocolates, Fast Food, Restaurant and Fun Zone directories use `components/ui/glass-folder-cards.tsx`, an adaptation of the supplied glass-folder design. The brand name appears on the glass, and a logo appears underneath where one is known. Selecting the folder lifts the preview photos and opens the original photo gallery; selecting an exposed photo or thumbnail opens a photo-focused adaptation of the supplied Warp Carousel, with arrow and swipe navigation. It uses React alone and does not reproduce the supplied WebGL stat-card renderer. The original business details remain visible below. If a directory's listing count does not match its curated names in `data/brands.json`, enhancement is skipped to avoid mislabelling stores. Original content remains visible without JavaScript. Some source descriptions, images and floor information are inconsistent and should be reviewed before publication.

The repository already uses shadcn's `components/ui` path and `app/globals.css`, with React, TypeScript and Tailwind configured. The standalone preview uses `clothing-folders.css` rather than the main app's Tailwind styles. To rebuild after edits:

```sh
npm ci --prefix orion-preview
NODE_PATH="$PWD/orion-preview/node_modules" ./orion-preview/node_modules/.bin/esbuild orion-preview/clothing-folders-entry.tsx --bundle --minify --format=iife --outfile=orion-preview/clothing-folders.js
```

Regenerating pages can overwrite the folder script and stylesheet references and can restore removed sections; reapply these preview customisations after an import.

## Celebration imagery and brand shelves

The Valentine’s Week event uses `images/celebration-concept.jpg` as an explicitly labelled generated illustration, not a documentary photograph; its original event image remains in the event photo grid. Image-only groups on event pages are displayed in responsive grids. The homepage floor directory uses a brand-focused adaptation of the supplied product-shelf design in `components/ui/skincare-product-shelf.tsx`, rather than fictional products, prices or shopping-cart features. It retains the existing moving rows, hover/focus pause, reduced-motion behaviour and brand detail dialogs. This adaptation uses React only, so the supplied demo's `motion` and `lucide-react` dependencies are not required by the preview. The existing shadcn, Tailwind and TypeScript paths are documented above.

The homepage requests the locally installed Berlin Sans FB typeface. It is a licensed font and is not bundled with the preview; visitors who do not have it installed receive Nunito Sans as a web fallback. To use Berlin Sans FB consistently for all visitors, provide webfont files and a licence that permits web embedding.
